# Dependências do Editor Estratégico

O Editor Estratégico utiliza @blocknote/core, @blocknote/react e @blocknote/mantine, versão 0.56.0, cuja licença declarada nos pacotes instalados é MPL-2.0. O texto da licença foi preservado em BlockNote-MPL-2.0.txt.

Os pacotes são distribuídos pelo npm e seu código de origem está indicado nos respectivos package.json. A implementação da Rotevo adiciona componentes próprios, schema de blocos e integração com a persistência privada, sem editar os arquivos de origem desses pacotes. Nenhum pacote comercial BlockNote XL foi adicionado nesta entrega.
